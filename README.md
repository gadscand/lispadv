# Lisp Adventures

> "Lisp was originally created as a practical mathematical notation for computer programs, influenced by (though not originally derived from) the notation of Alonzo Church's lambda calculus. It quickly became a favored programming language for artificial intelligence (AI) research."

I personally like AI, and I consider myself a mathematician, even though I don't have a degree. So, of course I would learn some Lisp dialects.

This repository contains some problems: Codewars, challenges, AOC, or just something fun. Written in different Lisp dialects, each dialect has its own folder. Explore it!

If you see something that could be written more beautifully (even though beauty is subjective), open an issue. I would love to see other solutions.
